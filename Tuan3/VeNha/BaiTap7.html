Flexbox và Box Model trong layout 

#wrapper { max-width: 700px; margin: auto; padding: 14px; border: 2px solid #24354b; }
.wrapper-body { display: flex; gap: 12px; }
.wrapper-body nav { flex: 0 0 23%; }
.wrapper-body main { flex: 1; }

Thầy cho header , nav , main , footer ; ta bổ sung phần tử chứa nav + main để căn ngang và không phụ thuộc float.
