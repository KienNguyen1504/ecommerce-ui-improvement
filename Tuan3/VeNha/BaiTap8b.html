CODE / GIẢI THÍCH

Cơ chế hover và focus-within 

.bat-rail li { flex: 1 1 0; min-width: 0; transition: flex-grow .3s; }
.bat-rail li:hover, .bat-rail li:focus-within { flex-grow: 1.6; }
.bat-more { opacity: 0; transform: translateY(8px); }
.bat-rail li:hover .bat-more, .bat-rail li:focus-within .bat-more { opacity: 1; transform: none; }

Trên màn hình lớn, năm thẻ chia đều chiều ngang; khi tương tác, thẻ đang chọn sẽ rộng hơn. :focus-within giúp người dùng dùng bàn phím thấy hiệu ứng tương tự hover.

Ảnh nhân vật dùng lại tài nguyên hình minh họa trong đề thầy cung cấp, phục vụ mục đích học tập.
