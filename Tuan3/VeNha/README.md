# CSS Lab Tuần 3 — Pastel Edition

Bài tập CSS Tuần 3 · Học phần Phát triển ứng dụng WEB/TMĐT · UEH.

## Trang tổng hợp
Mở `index.html` bằng Live Server; có liên kết đến từng bài độc lập `BaiTap1.html`, `BaiTap2.html`, `BaiTap4.html`–`BaiTap9.html` và `BaiTap8a.html`, `BaiTap8b.html`.

## Phạm vi thực hiện
- Bài 2: 2a–2e (font, background, overflow).
- Bài 3: chọn phương án b — làm Bài 4, 5, 6, 7.
- Bài 8: làm cả 8a và 8b. Bài 9: Font Awesome và ký hiệu dự phòng offline.
- Bài 1: CSS Diner (32 level) và CSS Speedrun (10 level). Ảnh minh chứng đã được thêm vào trang Bài 1.

## Thông tin cá nhân
Trang chủ hiện dùng thông tin cá nhân đã có trong bản người học cung cấp.

## Cấu trúc
- `css/style.css`: font Segoe UI, màu hồng–xanh pastel và toàn bộ CSS bài tập.
- `assets/`: minh họa có sẵn, không phụ thuộc link ảnh bên ngoài.
- `evidence/`: ảnh chụp giao diện thử nghiệm, kết quả QA và minh chứng game.
- `evidence/games/css-diner/`: 32 ảnh chụp minh chứng CSS Diner.
- `evidence/games/css-speedrun/css-speedrun-completed.png`: ảnh minh chứng CSS Speedrun hoàn thành 10 level.
