CODE / GIẢI THÍCH

Chín ảnh, ba cột, một cấu trúc 

.portfolio-grid { display: grid; grid-template-columns: repeat(3, minmax(0, 1fr)); gap: 18px; }
.portfolio-grid img { width: 100%; aspect-ratio: 640 / 420; object-fit: cover; }

Ảnh có tỷ lệ đồng nhất nhờ aspect-ratio , giữ bố cục ngay cả trước khi tải ảnh. Các mục trong gallery dùng li và a như cấu trúc đề.
