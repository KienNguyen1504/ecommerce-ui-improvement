Vì sao chọn inline-block? 

.study-menu li { display: inline-block; }
.study-menu a { display: inline-block; min-width: 122px; padding: 14px 20px; }
.study-menu a:hover { background: #d6f8f4; }

Giữ display:inline-block đúng yêu cầu đề; các phần tử không bị buộc xuống hàng như display:list-item mặc định. Liên kết dẫn đến các thẻ giải thích bên dưới, không phải nút giả.
